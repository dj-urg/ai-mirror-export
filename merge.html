    Platforms to include

    These files no longer match the checksum the extension recorded when it exported them, or arrived without their manifest, so we cannot confirm they are the original export. This usually happens when a file was opened and saved in Excel or another program, which can silently change dates, IDs and long texts. If you include them, the merge report lists every one so the change can be accounted for in your analysis. Where possible, ask for the original ZIP instead.

    Opening the merged files

    Analyse the merged files in 4CAT, the main toolkit for this project. Unzip the merged ZIP and upload all_messages_canonical_4cat.csv to 4CAT as a custom (CSV) dataset. How to use 4CAT is explained at 4cat.nl.

    Do not open or save the files in Microsoft Excel first: it cuts cells longer than 32,767 characters, can turn IDs and timestamps into numbers or dates, and saving from Excel changes the file. For a quick look outside 4CAT, use LibreOffice Calc, R or Python.

    Each merged row is copied unchanged from an export, with two extra columns, source_file and source_sha256, telling you where it came from.
