Research Participation

Before using this extension, please read the following information about your participation in the study.

What data is collected

  • Conversation messages (your questions and AI responses)
  • Web sources cited within conversations
  • Custom instructions or user profile, if you have set these

How it works

  • All processing is done locally in your browser
  • Data is saved as a ZIP of CSV files to your computer only
  • Nothing is sent to any server automatically
  • A random identifier is stored in your browser so that any files you later choose to share can be grouped together. It is not sent anywhere automatically and is regenerated after one year.

Research use

Exported files are intended for academic research. You decide which files to share with the researcher. Your participation is voluntary.

Withdrawal

You may stop participating at any time by uninstalling this extension. Delete any previously exported files if you no longer wish them to be used.

How Google capture works

Google renders AI replies gradually. The extension keeps capturing in the background even when this popup is closed. If the status looks stuck, close this popup and reopen it in a few seconds — then wait a second or two for the capture to appear.

    Privacy settings
    About this extension

    What this does

    • Extracts conversations from the current page
    • Bundles the data into a ZIP of CSV files, locally
    • Downloads file to your computer

    Privacy

    • All processing happens in your browser
    • No data sent to external servers
    • No permanent storage of conversations

    What's in the file?

    Exports are saved to your Downloads folder as a ZIP named <platform>_<conversation-id>_<timestamp>.zip. Inside is a <platform>_manifest_….json describing the files, plus one or more CSVs (each name starts with the platform and ends with the same id and timestamp):

    <platform>_metadata_….csv
    Title, model, message count, platform, extraction timestamp.
    <platform>_messages_….csv
    One row per turn: role (user/assistant), text, timestamp, model if known.
    <platform>_sources_….csv
    Cited web results — only if the conversation used search.
    <platform>_messages_canonical_….csv
    A shared schema across platforms so cross-platform analysis is possible.

    Your data stays on your device.

    Nothing is sent to any server. Files are saved to your Downloads folder.
